# Códigos para ChatGPT

Fuente: guía "584 Códigos Secretos para ChatGPT, Claude, Claude Code y Cowork" (Xabi Inteligencia Artificial, 2026). 259 entradas.

Prompt cues pensados para ChatGPT (GPT-5). La mayoría funcionan igual en Claude: úsalos como palabra clave al inicio del mensaje. Truco: apílalos con `|` → `Act as: Project Manager | SWOT | Format as: Table | Facts only`.

> Las secciones "Funciones Reales de ChatGPT" y "Comandos / Reales" son funciones propias de la app de ChatGPT/Codex: aquí sirven solo como referencia.

### ✍ Escritura y Estilo

| Código | Qué hace |
|---|---|
| `Humanize` | Reescribe en un tono natural y conversacional, eliminando el sonido robótico de la IA. |
| `Jargonize` | Lo contrario de ELI5: convierte lenguaje plano en estilo técnico y profesional. |
| `Simplify` | Reduce la complejidad de un texto sin perder el significado. |
| `Amplify` | Hace el contenido más enérgico, atractivo y persuasivo. |
| `Rewrite as: [estilo]` | Reescribe el texto en el estilo o formato de plataforma que indiques. |
| `Cleanup` | Elimina repeticiones y mejora la estructura sin cambiar el fondo. |
| `Hook` | Genera líneas de apertura más potentes para captar la atención. |
| `Expand` | Desarrolla y amplía una idea con más detalle, ejemplos y matices. |
| `Condense` | Comprime un texto largo manteniendo todo el significado importante. |
| `Reframe` | Reexpresa la misma idea desde otro ángulo, tono o público objetivo. |

| Código | Qué hace |
|---|---|
| `HighLevel` | Solo la visión general y conceptual, sin entrar en detalle. |
| `ExampleRich` | Muchos ejemplos y poca explicación teórica. |
| `QuickFix` | Solo el atajo rápido que resuelve el problema ahora. |
| `ClearCut` | Directo al grano, sin rodeos ni matices innecesarios. |
| `Academic` | Registro académico y riguroso, listo para citar. |
| `ELI12` | El escalón que faltaba entre ELI10 y ELI15. |
| `MOOD: [emoción]` | Cambia el estado de ánimo de la respuesta, más allá del tono. |
| `VOICE: [personaje]` | Escribe con la voz de un personaje o arquetipo (ej. VOICE: Sherlock Holmes). |
