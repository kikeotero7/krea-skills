# Prompt cues universales

Fuente: guía "584 Códigos Secretos para ChatGPT, Claude, Claude Code y Cowork" (Xabi Inteligencia Artificial, 2026). 30 entradas.

Funcionan igual en ChatGPT, Claude y Gemini.

### 🧩 Aprendizaje y Explicación

| Código | Qué hace |
|---|---|
| `Socratic` | Te enseña mediante preguntas y razonamiento guiado en vez de darte la respuesta directa. |
| `Analogy` | Explica un concepto difícil con una metáfora o analogía cotidiana. |
| `Quiz me` | Te hace preguntas para poner a prueba y reforzar tu comprensión. |
| `Mnemonic` | Crea una regla mnemotécnica o truco para memorizar algo. |
| `Teach back` | Tú explicas el tema y la IA corrige tus errores. Aprendizaje activo. |
| `Storytell` | Explica una idea a través de una narrativa o historia. |
| `One-liner` | Condensa una idea en una sola frase potente y memorable. |
| `Haiku` | Resume un tema o sensación en formato haiku. |

### 🧭 Frameworks, Decisión y Acción

| Código | Qué hace |
|---|---|
| `CRAFT` | Framework para prompts completos: Context, Role, Action, Format, Tone. Sirve para el 90% de las tareas. |
| `Mental model` | Aplica un modelo mental conocido (Pareto, inversión, primeros principios…). |
| `Decision tree` | Despliega las opciones de decisión en ramas con sus consecuencias. |
| `Tradeoffs` | Compara beneficios frente a costes de caminos rivales. |
| `Benchmark` | Compara herramientas o ideas según métricas concretas. |
| `Actions` | Entrega un plan rápido con los próximos pasos accionables. |
| `Steps` | Muestra la secuencia clara y ordenada de cómo hacer algo. |
| `Simulate` | Recorre un escenario o simulación paso a paso para anticipar resultados. |

### 🛠 Técnicos y Visualización

| Código | Qué hace |
|---|---|
| `Diagram` | Dibuja en ASCII o texto la estructura o el flujo de un sistema. |
| `Architect` | Diseña la arquitectura de un sistema software o un montaje físico. |
| `Formulate` | Convierte una idea en un modelo, fórmula o principio reutilizable. |
| `API shape` | Esboza endpoints, tipos de datos y comportamiento de una API. |
| `Code: [lenguaje]` | Devuelve código listo para usar y comentado en el lenguaje indicado. |
| `Debug` | Encuentra y explica los problemas de un fragmento de código. |
| `Thought process` | Muestra los pasos de razonamiento interno que sigue para responder. |
| `Timebox: X min` | Indica qué es realista lograr dentro de un marco de tiempo dado. |

### 🔥 Tendencia 2026

| Código | Qué hace |
|---|---|
| `Anti-slop` | Evita el lenguaje genérico, los clichés y el relleno típico de IA. El antídoto al texto "plano". |
| `Brutally honest` | Feedback directo y sin azúcar: lo que necesitas oír, no lo que quieres oír. |
| `Score it (1-10)` | Puntúa tu idea, texto o decisión con una nota y la justificación de por qué. |
| `Make it pop` | Hace el contenido más vivo, llamativo y con más gancho visual o verbal. |
| `Context stack: N` | Le dice a la IA que se apoye solo en los últimos N mensajes del chat. |
| `Reset` | Reinicia el contexto de trabajo en una conversación larga que se ha "ensuciado". |
