# Códigos visuales (edición 2026)

Fuente: guía "584 Códigos Secretos para ChatGPT, Claude, Claude Code y Cowork" (Xabi Inteligencia Artificial, 2026). 109 entradas.

No cambian el fondo de la respuesta: cambian su forma (apuntes, esquemas, paneles…). Funcionan en ChatGPT, Claude y Gemini. Úsalos así: **código + tema + nivel + para quién**. Ej.: `Swimlane: el proceso de alta de un cliente, para el equipo de operaciones`.

Combos que funcionan: `Iceberg + Brutally honest` (auditar un negocio) · `Comic strip + ELI5` (explicar algo técnico) · `Onepager + Facts only` (subir algo a dirección) · `Concept-map + Exam-mode` (estudiar).

Escribe los códigos en español sin tildes (`/infografia`, no `/infografía`).

### 📓 Papel y Apuntes

| Código | Qué hace |
|---|---|
| `Handwritten` | Explica el tema como apuntes escritos a mano: lenguaje llano, flechas, subrayados y márgenes. El más pedido para estudiar. |
| `Sticky-notes` | Reparte los puntos clave en post-its, una idea por nota. Ideal para ver de un vistazo todo lo importante. |
| `Napkin sketch` | Dibuja el proceso como si te lo explicaran en una servilleta: cuatro cajas, tres flechas y listo. |
| `Whiteboard` | Lo explica como en una pizarra de reunión, con bloques, llaves y conexiones entre ideas. |
| `Margin-notes` | Devuelve el texto con anotaciones al margen, como un libro subrayado por alguien que ya lo entendió. |
| `Index-cards` | Una idea por ficha numerada, listas para barajar, repasar y ordenar. |
| `Doodle` | Versión con garabatos: iconos simples y dibujitos en lugar de párrafos. |
| `Poster` | Convierte la idea en un póster de aula: titular grande, tres bloques y una conclusión. |

### 🔷 Diagramas y Estructura

| Código | Qué hace |
|---|---|
| `Mindmap` | Mapa mental con un concepto central y ramas jerárquicas hacia los subtemas. |
| `Flowchart` | Diagrama de flujo con decisiones sí/no y caminos alternativos hasta el final. |
| `Pyramid` | Ordena la información de lo esencial en la base a lo accesorio en la cima. |
| `Iceberg` | Separa lo que se ve en la superficie de lo que hay debajo. Icónico y se entiende al instante. |
| `Funnel` | Convierte el proceso en un embudo por etapas con pérdida en cada paso. Brutal para marketing y ventas. |
| `Venn` | Dos o tres conceptos, lo que comparten y lo que los diferencia. |
| `Quadrant` | Cuadrante 2x2 de consultoría: dos ejes, cuatro perfiles y dónde cae cada cosa. |
| `Layers` | Explica el sistema por capas, de la superficie al núcleo, indicando qué depende de qué. |
| `Before-after` | Dos columnas enfrentadas: cómo es ahora y cómo queda después del cambio. |
| `Orgchart` | Organigrama de quién es quién, qué hace y de quién depende. |
| `Roadmap` | Hoja de ruta por fases con hitos, entregables y dependencias entre ellos. |
| `Gantt` | Reparte las tareas de un proyecto en el tiempo, con solapes y duraciones. |

### 🎬 Narrativa Visual

| Código | Qué hace |
|---|---|
| `Comic strip` | Convierte el tema en viñetas de cómic con personajes y diálogo. El que mejor se ve en pantalla. |
| `Storyboard` | El proceso como guion gráfico de rodaje: plano a plano, con lo que pasa en cada uno. |
| `Movie-trailer` | Cuenta el tema como el tráiler de una película, con tensión y clímax. |
| `Kids-book` | Cuento infantil ilustrado con el concepto dentro. Simplifica hasta lo esencial. |
| `Emoji-only` | Explica el concepto usando solo emojis. Raro, divertido y muy compartible. |
| `Visual-metaphor` | Traduce la idea abstracta a una sola imagen mental potente y explica el paralelismo. |
| `Trading-card` | Ficha tipo cromo: nombre, stats, fortalezas y debilidades del concepto, herramienta o persona. |
| `Museum-label` | Explica el tema como el cartelito de una obra en un museo: breve, claro y con contexto. |

### 📊 Datos y Métricas Visuales

| Código | Qué hace |
|---|---|
| `Infographic` | Infografía completa: secciones, cifras destacadas, iconos y una conclusión final. |
| `Scorecard` | Puntúa por criterios con nota parcial, nota final y justificación de cada una. |
| `Heatmap` | Mapa de calor que señala dónde está lo importante y dónde no merece la pena mirar. |
| `Bar-race` | Compara magnitudes en barras ordenadas de mayor a menor, con la diferencia real marcada. |
| `Report-card` | Boletín de notas de un proyecto, una marca o una web, asignatura por asignatura. |
| `KPI-tree` | Descompone la métrica principal en las submétricas que realmente la mueven. |
| `Data-story` | Convierte una tabla de datos en la historia que cuentan esos números. |
| `Chart-it` | Elige el tipo de gráfico correcto para tus datos y te explica por qué ese y no otro. |

### 💼 Visual para el Trabajo

| Código | Qué hace |
|---|---|
| `Onepager` | El proyecto entero en una página: objetivo, presupuesto, equipo, hitos y métricas. |
| `Decision-matrix` | Puntúa y pondera cada opción por criterios, y declara una ganadora con su porqué. |
| `Meeting-agenda` | Convierte el lío en un orden del día con tiempos, responsables y decisión esperada. |
| `Process-map` | Mapea el proceso de principio a fin marcando dueño, entrada y salida de cada paso. |
| `Pitch-slides` | Esquema de presentación diapositiva a diapositiva, con el mensaje único de cada una. |
| `RACI` | Reparte responsable, aprobador, consultado e informado para cada tarea. |
| `Napkin-math` | Estimación rápida con números redondos y supuestos explícitos, en cuatro líneas. |
| `Status-report` | Estado del proyecto en semáforo: qué va bien, qué está en riesgo y qué está bloqueado. |

### 🎓 Visual para Estudiar

| Código | Qué hace |
|---|---|
| `Visualize learning` | Explica el tema apoyándose en imágenes mentales y esquemas en vez de definiciones. |
| `Exam-mode` | Deja de explicarte y te examina: pregunta, corrige y señala qué no te sabes. |
| `Concept-map` | Conecta todos los conceptos del tema con flechas etiquetadas que explican la relación. |
| `Color-code` | Agrupa la información por colores según tipo, dificultad o importancia. |
| `Diagram-first` | Empieza siempre por el esquema y solo después añade el texto que lo explica. |
| `Zoom-levels` | El mismo tema en tres zooms: vista de pájaro, nivel medio y detalle fino. |
| `Label-it` | Describe el objeto o sistema con todas sus partes etiquetadas una a una. |
| `Visual-summary` | Resume el tema entero en un solo esquema que quepa en una pantalla. |

### 🔀 Flujo y Proceso

| Código | Qué hace |
|---|---|
| `Swimlane` | El proceso por carriles: un carril por persona o equipo responsable. |
| `Cycle` | Proceso circular que se repite, con lo que dispara cada vuelta. |
| `Fishbone` | Diagrama de espina de pescado: el problema y todas sus causas por familias. |
| `Journey-map` | El recorrido del cliente por etapas, con lo que hace y lo que siente en cada una. |
| `Value-chain` | La cadena de valor eslabón por eslabón, señalando dónde se gana dinero. |
| `Sankey` | Flujo de cantidades que se reparten y se pierden por el camino. |
| `Waterfall` | Cascada que explica cómo se pasa de una cifra inicial a la final, paso a paso. |
