# Códigos para Claude (chat)

Fuente: guía "584 Códigos Secretos para ChatGPT, Claude, Claude Code y Cowork" (Xabi Inteligencia Artificial, 2026). 119 entradas.

Los códigos pensados para Claude. Los que empiezan por `/` están instalados en este repo como comandos de Claude Code (ver `.claude/commands/`); los que van en MAYÚSCULAS (L99, ULTRATHINK, HARDMODE…) se escriben como palabra clave al inicio del mensaje.

### ✍ Escritura y Estilo

| Código | Qué hace |
|---|---|
| `/ghost` | Reescribe el texto eliminando los patrones típicos de la IA (guiones largos, "espero que esto ayude"), haciéndolo indetectable para detectores de IA. |
| `/mirror` | Analiza un texto de muestra proporcionado y genera respuestas imitando exactamente ese estilo de escritura. |
| `/raw` | Elimina todo el formato Markdown y entrega una respuesta limpia en texto plano. |
| `/voice` | Fija un tono específico (ej. académico, sarcástico, corporativo) y lo mantiene durante toda la conversación. |
| `/punch` | Edita el texto para que cada frase sea más directa, concisa e impactante. |
| `/flow` | Reestructura párrafos y oraciones para mejorar la fluidez y la transición entre ideas. |
| `/trim` | Elimina la paja y el relleno de un texto sin perder el significado original. |
| `/hook` | Reescribe exclusivamente la línea de apertura para captar la atención del lector instantáneamente. |
| `/rephrase` | Toma una idea y la expresa de una manera completamente diferente. |
| `/polish` | Transforma un texto tosco o un borrador rápido en un documento con sonido profesional. |
| `/localize` | Adapta un texto a otro idioma o mercado conservando tono, intención y matices culturales. |

### 🧠 Pensamiento y Razonamiento

| Código | Qué hace |
|---|---|
| `L99` | Fuerza a Claude a comprometerse con una opinión firme y alcanzar la máxima profundidad, reduciendo respuestas ambiguas tipo "depende de tu situación". |
| `/deepthink` | Obliga al modelo a razonar capa por capa, mostrando su proceso de pensamiento antes de dar la respuesta final. |
| `OODA` | Aplica el marco militar Observar-Orientar-Decidir-Actuar. Ideal para respuestas a incidentes o planificación estratégica. |
| `CHAINLOGIC` | Muestra explícitamente cada paso del razonamiento lógico para que el usuario pueda seguir la cadena de deducciones. |
| `/blindspots` | Analiza la consulta para encontrar ángulos, riesgos o preguntas que el usuario olvidó considerar. |
| `OVERTHINK` | Sobre-analiza deliberadamente una situación para captar detalles minúsculos que normalmente se pasarían por alto. |
| `/unpack` | Descompone una idea compleja en cada uno de sus componentes fundamentales. |
| `INVERT` | Aborda la resolución de un problema pensando en él completamente al revés (inversión de modelos mentales). |
| `/layered` | Proporciona la respuesta estructurada en tres niveles: superficial, intermedio y experto. |
| `XRAY` | Ignora la respuesta superficial para buscar la causa raíz o la verdad subyacente de una situación. |
| `ULTRATHINK` | Empuja a Claude a generar sus respuestas más largas y razonadas. Útil para decisiones de alto riesgo. |
| `/skeptic` | En lugar de responder directamente, Claude cuestiona y desafía la premisa de la pregunta del usuario. |
| `HARDMODE` | Destierra frases como "depende" o "considera ambas opciones", forzando a Claude a tomar una decisión definitiva. |
| `/firstprinciples` | Razona desde primeros principios: descompone el problema hasta sus verdades básicas y reconstruye la solución desde cero. |

### ⚔ Análisis y Estrategia

### 👻 Modos y Personajes

| Código | Qué hace |
|---|---|
| `/nofilter` | Proporciona la opinión más directa y honesta posible, eliminando la cortesía artificial (sin saltarse las políticas de Claude). |
| `BEASTMODE` | Empuja la calidad del resultado al máximo, usando el mayor nivel de esfuerzo disponible. |
| `CEOMODE` | Responde asumiendo el rol de un CEO experimentado tomando decisiones de negocio de alto impacto. |
| `OPERATOR` | Maneja una tarea de principio a fin de manera autónoma, sin pedir aclaraciones adicionales. |
| `SENTINEL` | Actúa como un guardián, revisando todo el contexto en busca de errores críticos, riesgos y detalles perdidos. |
| `PERSONA` | Permite definir un rol hiper-específico (ej. "DBA senior cínico"). Uno de los comandos más efectivos en todos los modelos. |
| `/stealth` | Optimiza el texto para sonar humano, reduciendo los marcadores típicos de escritura generada por IA. |
| `/devmode` | Adopta un tono estricto de ingeniero a ingeniero. Asume contexto técnico avanzado y omite explicaciones básicas. |
| `FOUNDER` | Proporciona consejos de startup y negocio desde la perspectiva de un fundador experimentado. |
| `/closer` | Genera copy de ventas o mensajes diseñados específicamente para cerrar un trato o conversión. |
| `/negotiate` | Escribe un guión de negociación optimizado para obtener el mejor resultado posible. |
| `/therapist` | Habla a través de una situación con empatía y estructura, como lo haría un terapeuta profesional. |
| `/unlocked` | Reduce la cautela por defecto y va al grano con la respuesta más directa (dentro de las políticas de Claude). |
