# KREA Skills

Skills, comandos y códigos de prompting de KREA Digital Studio para Claude Code.
Copia la carpeta `.claude/` en cualquier proyecto para tenerlos disponibles.

## Skills

- `krea-apps`: estándar para crear apps de clientes (móvil y ordenador, datos sincronizados en la nube, PDF, envío por WhatsApp, demo y portafolio).
- `codigos-secretos`: códigos de prompting.
