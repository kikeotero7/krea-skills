# KREA Skills

Skills, comandos y códigos de prompting de KREA Digital Studio para Claude Code.
Copia la carpeta `.claude/` en cualquier proyecto para tenerlos disponibles.

## Skills

- `krea-apps`: estándar y forma de trabajar para apps, webs y portafolios de clientes (móvil y ordenador, datos sincronizados en la nube, PDF, envío por WhatsApp, demo, portafolio y © de KREA al pie).
- `codigos-secretos`: códigos de prompting.
